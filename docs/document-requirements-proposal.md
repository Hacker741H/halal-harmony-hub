# Proposition — exigences documentaires configurables

Ce document est une proposition à valider par le métier. Il n'active aucune règle, alerte, table ou migration.

| Entité | Documents envisagés |
| --- | --- |
| Véhicule | Assurance, carte grise, visite technique selon la réglementation locale |
| Moto | Assurance, carte grise, visite technique selon la réglementation locale |
| Chauffeur | Permis avec catégorie et date d'expiration |
| Employé | Contrat et pièce d'identité si la politique RH le requiert |
| Exploitation | Bail, certificats et autorisations agricoles selon le contexte |

Un futur lot devra définir les catégories obligatoires par organisation, l'entité concernée, les périodes de grâce, les rôles responsables et la stratégie d'alerte avant toute automatisation.
